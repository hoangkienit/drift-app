# Food Delivery App

## Overview
This **Food Delivery App** is a three-sided platform that connects **users**, **merchants**, and **drivers** for a seamless food ordering and delivery experience.

## Features

### 📱 For Users (Customers)
- Browse restaurants and order food
- Track orders in real-time
- Secure online payment options
- Rate and review restaurants

### 🍔 For Merchants (Restaurants)
- Manage menu and pricing
- Receive and process orders
- Handle promotions and discounts

### 🚗 For Drivers (Delivery Partners)
- Accept delivery requests
- Optimized route navigation
- Flexible working hours

## 🚀 Tech Stack
- **Frontend:** React Native  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Payments:** Stripe ,VNPay ,ZaloPay  
- **Maps & Navigation:** Google Maps API, Mapbox API
